# AgriConnect 🌾

## AI Smart Direct Farmer Marketplace

AgriConnect is an AI-powered direct farmer-to-consumer marketplace that helps farmers sell their produce without middlemen.

## Problem Statement

Farmers often receive lower profits because middlemen control pricing and market access. AgriConnect enables farmers to connect directly with buyers and make informed decisions using AI recommendations.

## Features

- Farmer Verification
- Farmer Profile
- Product Listing
- Smart Quotation Marketplace
- Explainable AI Buyer Recommendation
- Direct Purchase Option
- Secure Payments
- Order Tracking
- Ratings & Reviews
- Tamil & English Support
- Voice Assistant

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: SQLite
- Version Control: Git & GitHub

## How to Run

1. Clone the repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Start the application:

```bash
python backend/app.py
```
